# Auto BeamScientist website

Buildless project homepage. The vision and selected research manuscript are intentionally presented at a high level.

Serve `dist/` with `python3 -m http.server 8080 --directory dist`.

The PDF and preview are copies of `runs/pgcd/paper/preprint1.pdf` and `runs/pgcd/paper/build/first_page.png`. Update both together when the manuscript changes. This manuscript is a simulation study; peer-review status has not been established. The homepage makes no claim of publication or verified novelty. The hero curves are decorative artwork, explicitly labeled in accessible text and code.

Run `python3 verify_site.py` to check local links, content markers, and the manuscript fingerprint. No backend, account system, or simulation execution is included.
